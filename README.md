# ДЗ № 1. Изучение средств защиты ОС GNU/Linux

Работа выполнена на Fedora Server 44 (aarch64) в виртуальной машине UTM.

Студенческий номер: M265896

## Выполнение заданий

1. Создала пользователя user1 с UID 1234, добавила его в группу students
   и настроила максимальный срок действия пароля — 90 дней.
2. Нашла файлы с битом Set-UID. Проверила реальные и эффективные UID
   процессов на примере passwd.
3. Создала копию cat, назначила владельцем root и установила Set-UID.
   После этого удалось прочитать защищённый тестовый файл.
4. Создала копию chown и назначила ей CAP_CHOWN. Проверила изменение
   владельца файла без sudo.
5. Настроила правило sudo для user1, разрешающее изменять системное время.
   Проверила выполнение команды.

## Файлы с результатами

- `mephi-screenshot.png` — скриншот терминала со студенческим номером
- `history.out` — история команд, выполненных в ходе работы
- `stat.out` — сведения о правах /home/user1, cat-lab и chown-lab
- `getcap.out` — привилегия CAP_CHOWN для chown-lab
- `passwd` — сведения об учётных записях пользователей
- `group` — сведения о группах, включая students
- `shadow-user1-safe` — параметры пароля user1 без хеша пароля
- `sudoers` — основной файл конфигурации sudo
- `user1-time` — правило для изменения времени пользователем user1
- `sudo-user1.out` — результат проверки разрешённых команд sudo
- `find-setuid.out` — список файлов с битом Set-UID
- `process-monitoring.out` — результаты мониторинга процесса passwd (RUID 1000, EUID 0)

## Примечание

Для экспериментов с Set-UID и capabilities использовала копии системных
утилит, чтобы не изменять оригинальные программы.
Вместо полного /etc/shadow приложила только сведения о user1 без хеша
пароля, поскольку репозиторий публичный.
